# NetworkWalks Week 2 Project - Footprinting & Reconnaissance

This repository documents the practical tasks and screenshots completed during the Week 2 Cybersecurity Internship at *NetworkWalks*, an IT and cybersecurity training platform focused on hands-on network security and ethical hacking labs.

## Completed Work: Module 1 (Footprinting with Multiple Tools)
In this module, various reconnaissance tools were used to gather public intelligence and map the target's footprint:
* *whois*: Queried public domain registration details, registrar information, and name servers.
* *whatweb*: Identified underlying web technologies, server software, and frameworks.
* *nslookup*: Resolved the target domain to its corresponding IP address.
* *curl -I*: Inspected HTTP response headers to analyze server configurations.
* *wafw00f*: Checked for the presence of a Web Application Firewall (WAF).
* *dnsrecon*: Enumerated DNS records to uncover domain infrastructure.
